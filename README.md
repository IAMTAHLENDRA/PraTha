<h1 align="center">💕 PraTha</h1>

Wedding website of Pranjali and Thalendra — a placeholder for now; the design and photos come later.

Live: https://iamtahlendra.github.io/PraTha/

## 🚀 Run & deploy

```bash
npm install
npm start        # dev server at localhost:3000
npm run build    # production build into build/
npm run deploy   # publish to GitHub Pages (gh-pages branch)
```

Photos go in `public/photos/` later.
